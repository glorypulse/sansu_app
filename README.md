# sansu_app

算数の練習に使える、ブラウザ向けのミニアプリ集です。

## アプリ

- [どこのマスかな？](dokono_masu_kana.html)：上下左右の位置を手がかりに、くだもののマスを探します。
- [10になるペアマスター](make_10_master.html)：10になる組み合わせや、繰り上がりを練習します。成績はブラウザに保存されます。

## 使い方

使いたいHTMLファイルをブラウザで開いてください。インストールやビルドは不要です。

`make_10_master.html` は外部CDNからライブラリやフォントを読み込むため、利用時にインターネット接続が必要です。

## どこのマスかな？

外部ライブラリ・通信・ビルドは不要です。HTMLを直接開くか、静的ホスティングで利用できます。

- Lv.1：縦一列／横一列で、一方向の条件を練習します。
- Lv.2（初期設定）：段全体を選んで確定した後、その段のマスを選びます。
- Lv.3：縦横の条件を同時に提示し、必要に応じてヒントを使います。
- Lv.4：同時提示でヒントなし。答え表示で終了することはできます。

設定変更は新しい問題を開始します。ヒントはLv.1では数える向き→正解マス、Lv.2の段選択では正解の段、マス選択とLv.3では段→正解マスを示します。答え表示後や正解後は「つぎのもんだい」で進みます。

### 保護者向けの記録

ブラウザのlocalStorageに直近200問を保存し、直近10問の概要を表示します。JSON書き出しには問題の方向・盤面・正解座標、段階ごとの確定回答、経過時間、ヒント、読み上げ、終了理由が含まれます。座標は0始まりです。単に選択を変えただけでは誤答としません。「補助なし正解」にも再試行後の正解が含まれるので、初回正答はanswerイベントで確認してください。

答えを表示した問題は正解として記録しません。未完了で次へ進んだ場合はskipped、ブラウザを閉じたときの途中記録はactiveのままです。まだ操作・読み上げのない問題は、次へ進むまで保存しません。時間には休憩も含まれ、記録は理解の程度や原因を診断するものではありません。

名前などの個人情報は収集せず、外部送信もしません。履歴は利用するブラウザ・URLごとで、プライベートモードやfile URLでは保存できない場合があります。保存失敗時も学習は続けられます。履歴削除はこのアプリの記録のみが対象です。

読み上げはWeb Speech APIに対応したブラウザで動作し、音声・動作は端末に依存します。

### 検証

`node --test tests/*.test.cjs`

依存パッケージ不要のテストで、各アプリの回答処理や記録を確認します。実ブラウザのレイアウト・音声品質を保証するテストではありません。
